# PDFx

A personal, fully offline PDF suite for Android, built on MuPDF. See [PLAN.md](PLAN.md) for what it
is, how it is built and what comes next.

Install the latest APK from the Releases page. Screenshots of every build are on the
`screenshots` branch.
